Set It Up

Install the app, make a folder and paste one box of text. Then Claude interviews you and builds the rest itself.
Windows and Mac Desktop or laptop About 1 hour
How long this takes

About 20 minutes of clicking, then 30 to 45 minutes of Claude interviewing you. You only do it once, and you can stop halfway and carry on later.

You'll need a desktop or laptop. Once it's built you can use it from your phone, and that's covered at the end.

01 / The App And Your Account

1

Get a paid Claude account

Go to claude.ai, sign up with your Google email and upgrade to Pro. The free plan doesn't include Claude Code.

2

Install the Claude desktop app

Claude Code comes inside the app, so this is the only thing you install.

Mac
  1. Download Claude for Mac
  2. Open the downloaded file from your Downloads folder
  3. Drag Claude into your Applications folder
  4. Open Claude from Applications or Launchpad
  5. If you see a security warning, go to System Settings → Privacy & Security and click Open Anyway
  6. Sign in with the account from step 1
Windows (PC)
  1. Download Claude for Windows
  2. Run the downloaded file and follow the installer
  3. Open Claude from your Start menu
  4. Sign in with the account from step 1

02 / Your Claude Folder

1

Make an empty folder called Claude

Put it in your Documents folder or on your Desktop. Keep it out of Google Drive and iCloud folders for now, because syncing can get in the way while Claude's working. We'll sort your backup at the end.

2

Open the Code tab

At the top of the Claude app you'll see tabs. Click Code.

3

Choose Local, then pick your folder

Under the message box there are two controls. Click the first and choose Local, which means your own computer. Click the one beside it, choose Open folder… and pick your Claude folder.

4

Check two settings

In the row under the message box, set the mode to Manual for your first few sessions, so Claude asks before it does anything. Then in Claude's Settings, open Privacy and look at Help improve our AI models. If it's on, your chats and coding sessions can be used to train Claude. It's your choice, so choose on purpose.

Check this every time

To start a new session, click New session in the Code tab. Each time, glance at the folder under the message box. If it says Claude, you're in the right place. Most "it's forgotten who I am" problems come from being in the wrong folder.

Claude will ask your permission as it works

The first few times it downloads a file or creates a folder, a small prompt asks you to allow it. Click to allow. That's the approval system working, and you stay in charge of what happens on your computer.

Closed your laptop halfway through?

Start a new session in the same folder and paste the same box. Claude keeps a progress file, sees where you stopped and picks up from there.

04 / What Happens Next

From here it's a conversation. Claude asks, you answer.

  • It looks before it asks. Claude checks what it can already learn about you, and asks if you've been using ChatGPT or Claude so it can bring that history over.
  • It interviews you, one question at a time. Who you are, how you work, your goals, and the writing you can't stand. Answer like you're talking to a mate. Honest and specific beats polished.
  • The ideal client interview goes deep. It's the longest part and the most valuable. Early on Claude asks whether your buyer is buying for their own life or for their job. The interview reshapes itself around your answer.
  • You approve every file before it's saved. Claude drafts, shows you and only saves when you say yes. Your edits always win.
  • It ends with proof. Claude writes a few lines in your voice, to your person, and asks you one question: does this sound like you?
Talk instead of type

A voice-to-text tool makes the interview go twice as fast, and your answers come out more like you. I use Wispr Flow for nearly everything I say to Claude.

What you'll have when it's done

Your Claude folder will have two folders in it. ABOUT ME holds your four foundation files, which cover your voice, your ideal client, your company and your writing rules. PROJECTS is where your work goes, and it starts with a longer profile of your ideal client. Claude also writes a CLAUDE.md instruction sheet that loads your foundation files every session, and a /weekly-check-in command that keeps them current.

05 / Your Daily Workflow

Every new session starts with Claude already knowing you. Just say what you're working on.

For a new projectI'm starting a new project called [name]. Create a folder for it inside my PROJECTS folder, then let's begin.
For an existing projectOpen the [project name] folder in PROJECTS. Here's what we're working on today: [brief]
For strategy workI want to think through [topic]. Read my foundation files first, then let's have a working conversation. I'll share my thinking and I want pushback, suggestions and clarity.
At the end of a sessionSummarise what we decided and built today. Save it as session-notes.md in the [project name] folder, and add an opening message I can paste next time to pick up where we left off.

Once a week

Type /weekly-check-in at the start of any session. Claude reviews your foundation files, flags what's gone stale and asks what's changed. It takes about ten minutes.

06 / Troubleshooting

Check here before assuming anything's broken.

The Problem What's Causing It How to Fix It
Claude asks what it should already know, or can't find a file You're in the wrong folder Start a new session and pick your Claude folder under the message box
Setup got interrupted Closed laptop, lost connection, ended the session Paste the Section 03 box again in a new session. It resumes where you stopped.
The download step fails A hiccup reaching the hosting site Tell Claude: "Try the downloads again, and if they still fail, use raw.githubusercontent.com/how-to-elevate/elevate-claude-code-setup/main/ instead of the how-to-elevate.github.io address."
Claude says it needs Git (Windows) Some jobs use this small free tool Install it from git-scm.com/download/win with the default settings, then restart the Claude app. You don't need a GitHub account.
I can't see a Code tab You're on the free plan, or the app's out of date Check your plan at claude.ai, then update the app
Claude keeps asking permission That's the approval system Allow what makes sense. Part 3 covers how to let it run with fewer questions.
The writing sounds generic Your writing rules are too vague Run /weekly-check-in and add the specific words and patterns you hate
Replies are getting slow or confused The session's got too long Start a fresh session. One job per session works best.

07 / Your Phone And Your Backup

Use it from your phone

The Claude phone app has a Code tab too. It can reach sessions running on your computer, as long as the computer stays on with the Claude app running.

Phone accessI want to use this workspace from my phone. Check what's available on my plan, then walk me through setting it up, one step at a time.

Back up your workspace

Everything you build lives in your Claude folder, so give it a second home. Google Drive is the simple way, and you're probably using it already. This uses Plan mode, which you'll learn in Part 3, so come back to it after that if you like.

Google Drive backupI want my Claude folder backed up to Google Drive automatically, so I'd lose nothing if this computer died. It should only ever copy, and never delete anything. Check whether Google Drive for desktop is installed and walk me through it if it isn't. Make a plan first, and tell me what you'd leave out of the backup.
One rule for passwords and API keys

An API key is a password one app uses to talk to another. Never paste a password or API key into the chat. If something needs one, tell Claude and it'll help you set it up safely. If a key lands in a conversation by accident, treat it as exposed and replace it.
